# Retain skills

Skills and a connector for [Retain](https://retainapp.ai): search and capture your meetings, tasks and threads from your assistant.

- **Claude Code:** `claude plugin marketplace add ryanrapp/retain-skills` then `claude plugin install retain@retain`.
- **Codex:** `codex plugin marketplace add ryanrapp/retain-skills` then `codex plugin add retain@retain`. Restart Codex, then sign in to the Retain connector when it asks.
- **Other harnesses that install skills from GitHub:** point them at `skills/` (`retain-search`, `retain-capture`).

The connector is https://retainapp.ai/api/private/mcp and asks you to sign in to Retain. This copy is for https://retainapp.ai; to use another Retain server, install from the Retain desktop app. Version 1.2.0-2. Generated; do not edit here.
