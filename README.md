# Retain skills

Skills and a connector for [Retain](https://retainapp.ai): search and capture your meetings, tasks and threads from your assistant.

- **Claude Code:** `claude plugin marketplace add <owner>/<repo>` then `claude plugin install retain@retain`.
- **Other harnesses that install skills from GitHub:** point them at `skills/` (`retain-search`, `retain-capture`).
- **ChatGPT / Codex:** add `plugins/retain` as a local plugin.

The connector is https://retainapp.ai/api/private/mcp and asks you to sign in to Retain. Version 1.2.0-2. Generated; do not edit here.
